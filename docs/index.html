当机器学会弹钢琴

ServoPiaBot 使用 60+ 个舵机模拟手指按压琴键，通过 MIDI 解析驱动舵机阵列， 探索机器如何赋予音乐「情感」与「灵魂」。

⭐ GitHub 仓库 🎬 观看演示
Project Story

背后的思考

传统自动演奏设备按键力度均匀、没有灵魂；机械震动与噪声让弹奏不够干净； 固化程序导致节奏反常、听感机械。ServoPiaBot 试图回答一个更有趣的问题——

🧠

学习式演奏

是否可以通过学习的方式让机器产生情感？对声音进行操作，输出不均匀的舵机角度和速度来模拟力度变化。

🎼

音乐技巧探索

通过舵机角度微调和速度曲线，探索颤音、滑音、力度渐变等真实演奏中才有的音乐技巧。

🤖

自主即兴

终极目标：让机器学会自主即兴创作，不仅仅是「播放」MIDI，而是真正「演奏」音乐。

🔧

全开源

硬件、固件、上位机脚本全部开源。从 STM32 HAL 库到 MIDI 解析 Python 脚本，均可自由修改与分发。

Design Evolution

方案演进历程

从四种主流方案中不断对比、迭代，最终选定最务实的舵机方案。

Plan 4 · 已否决

机械臂 + 灵巧手

目前技术不成熟，DIY 门槛过高，成本不可控。且永远不可能达到人类钢琴大师水平。

Plan 3 · 已否决

滑轨 + 机械手

无法弹奏复杂和弦；滑轨速度有限，节拍快的曲子跟不上。成本 ¥1000+。

Plan 2 · 已否决

推拉电磁铁

物理噪声大，且单个电磁铁（AH-520B ¥7.5）成本高于舵机。暂未找到成熟开源方案。

Plan 1 · 最终方案 ✓

数字舵机阵列（PCA9685 + SG90 × 60）

单个 SG90 仅 ¥5.5，60 个总成本 ¥385。PCA9685 模块支持 16 路 PWM， 4 个级联驱动 64 路舵机。物理噪声可通过物理隔离 + 真空消音降低， 加大音响音量后噪声不明显。具备成熟的开源生态（参考 automatic_gita）。

Wiring

接线与通信

I²C 总线级联架构，4 个 PCA9685A 模块控制 60+ 路舵机。

🔗 I²C 级联拓扑

  • STM32 I²C → PCA9685A #1 (0x40) → 舵机 1-16
  • PCA9685A #1 → PCA9685A #2 (0x41, 焊 A0) → 舵机 17-32
  • PCA9685A #2 → PCA9685A #3 (0x42, 焊 A1) → 舵机 33-48
  • PCA9685A #3 → PCA9685A #4 (0x43, 焊 A0+A1) → 舵机 49-60

⚡ 供电方案

  • LRS-150-5 电源 → PCA9685A V+ / GND（舵机供电）
  • ST-Link → STM32（调试阶段供电）
  • 独立运行：2S 锂电池或充电宝供电

⚠️ Safety

安全须知

⚡

接线前测量

务必用万用表（交流 750V 档）测量三芯电线零火线。L-N = 220V、L-E = 220V、N-E = 0V 方可使用。

🧤

禁止带电操作

接线时拔掉插头，佩戴绝缘手套。220V 交流电涉及生命安全，务必谨慎。

🔌

电源独立供电

舵机供电与主控供电分离。LRS-150-5 专供舵机阵列，STM32 通过 ST-Link 或电池独立供电。

🔊

降噪策略

60 个舵机同时工作噪声明显。通过物理隔离、真空消音、加大音响音量来掩盖机械噪声。
